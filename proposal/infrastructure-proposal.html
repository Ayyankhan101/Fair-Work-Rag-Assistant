1. Executive Summary

This proposal outlines infrastructure requirements for the Fair Work Awards & NES Knowledge Assistant — a RAG-powered LLM system covering 130 Modern Awards and the National Employment Standards.

Key Requirements:
  • Embedding Model: Local ONNX inference (CPU, no GPU required)
  • Vector Database: TurboVec quantized storage (4-bit, CPU)
  • LLM Inference: Groq API (serverless, pay-per-token)
  • Reranker: Cohere rerank-english-v3.0 (optional, +67% accuracy)
