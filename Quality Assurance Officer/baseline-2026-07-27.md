## Blocking findings

### B-001: CI imports functions that do not exist

`.github/workflows/ci.yml` imports:

```text
src.rag.build_rag_chain
src.cag.build_cag_chain
src.router.route_query
```

The implementation defines:

```text
src.rag.create_rag_chain
src.cag.get_cag_cache
src.router.route_question
```

Impact: the `test-imports` job cannot pass as written.

Severity: S1.

### B-002: lint and format gates fail

`ruff check` reports unused imports, imports after path mutation, unused variables, and f-strings without placeholders. `ruff format --check` reports 16 files.

Impact: the CI lint job cannot pass.

Severity: S1 because the required build gate is red.

### B-003: award audit contains unresolved names

`data/award_audit.json` contains generic or malformed values, including:

```text
16.pdf -> Award 2020
21.pdf -> Award 2016
ma000025.pdf -> Award 2020
ma000075.pdf -> Award 2020
ma000091.pdf -> Award 2020
PR985112.pdf -> MA000002 PR985112
PR991060.pdf -> MA000095 PR991060
```

Other titles are truncated or malformed, such as `Employees) Award 2016` and `Industry Award 2010`.

Impact: per-award coverage, filtering, citations, and source URLs cannot be trusted for these records.

Severity: S1.

### B-004: stored evaluations are too narrow for release evidence

The hard evaluation has 25 questions and reports 87.55% overall accuracy. The PRD evaluation has 12 questions. Neither set proves coverage across every Award, all NES areas, routing failures, negative rejection, corpus freshness, UI errors, concurrency, or security.

Impact: current evaluation files cannot support a full QA pass.

Severity: S2.

### B-005: evidence can become stale

Stored result JSON does not establish, in the summary inspected, a complete link to commit SHA, corpus checksum/version, vector-store version, prompt version, model version, and run timestamp.

Impact: results cannot be compared reliably after source or implementation changes.

Severity: S2.

## Baseline decision

Status: fail.

Release is blocked by B-001, B-002, and B-003. The next work item is to repair the offline build gates, then replace the incomplete award-name audit with a strict corpus gate.
